EMAIL & INBOX MANAGEMENT — PORTFOLIO PROJECT 02

FILES
- index.html: demo layout and controls
- style.css: responsive design
- app.js: sample emails and interactions
- manifest.json: installable web app metadata
- sw.js: basic offline caching
- README.txt: instructions

PUBLISH WITH GITHUB PAGES
1. Create a separate repository, for example: email-inbox-management-demo
2. Extract this ZIP on your phone.
3. Upload index.html, style.css, app.js, manifest.json, and sw.js to the repository root.
4. Commit the changes.
5. In repository Settings > Pages, publish from the main branch and root folder.
6. Open the published site and test the inbox, search, sorting, priority flags, follow-up queue, archive, and sample reply draft.

DEMO FEATURES
- Fictional inbox messages
- Search and sort
- Priority and follow-up flags
- Archive sample messages
- Compose a sample draft and preview it in the inbox
- Workflow explanation for a portfolio visitor
- Phone and desktop layouts

IMPORTANT
No real account is connected. No message is sent. Do not enter real confidential information.
